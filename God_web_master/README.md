# God Web Master v5.0

Professional web scanner and system information gatherer, designed for security professionals and educators.

## Features

- **Web Technology Detection** – Identify technologies used by any website (asynchronous & cached)
- **Client Information Gathering** – OS, network, geolocation (with privacy considerations)
- **Security hardened** – Data encryption, rate limiting, User‑Agent rotation, input sanitization
- **Multiple interfaces** – Interactive colored menu or full CLI
- **Multiple output formats** – JSON, CSV, HTML
- **Production ready** – Docker support, comprehensive logging, unit tests
